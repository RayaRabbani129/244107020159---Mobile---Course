## AI Prompt Challenge
Pilih GridView jika:
1. Anda menginginkan dashboard berbentuk kartu yang padat
Data bersifat seragam
Ingin tampilan lebih cepat dibuat dan rapi

2. Pilih LayoutBuilder + Column jika:
Anda ingin tampilan lebih semantik dan mudah dibaca
Konten lebih panjang dan membutuhkan hierarki
Aksesibilitas dan struktur informasi lebih penting daripada densitas visual
